# Speak Better with Alvin

A free, static English-speaking guide from Level Up with Alvin. The site contains 14 original lessons, a phrase bank, optional local-only lesson progress, and a GCash support page.

## Local preview

From this directory, run `python3 -m http.server 8765` and open `http://localhost:8765/`.

## Publishing

Publish the repository's `main` branch root with GitHub Pages. The site needs no build step, accounts, database, or Supabase project. Keep `index.html`, `app.js`, `lessons.js`, `styles.css`, `.nojekyll`, and `assets/` together.

## Content and privacy

Lessons are original and use short everyday dialogues followed by speaking practice. DK's *English for Everyone: Everyday English* informed the broad real-life practice approach; no book text, artwork, audio, or exercises are reproduced. Lesson completion is saved in the visitor's browser with `localStorage`. No progress or payment details are sent to this site. The GCash QR image was supplied by Alvin for this public support page.
